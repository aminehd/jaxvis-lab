# jaxvis-lab

Three repos that make one thing: pictures of JAX code running.

| | |
|---|---|
| [`jaxvis`](https://github.com/aminehd/jaxvis) | the framework — animates any JAX function by interpreting its jaxpr |
| [`formula-a-day`](https://github.com/aminehd/formula-a-day) | a daily ML formula, built with it |

The site is published from `formula-a-day/docs` →
**https://aminehd.github.io/formula-a-day/**

```bash
git clone --recurse-submodules https://github.com/aminehd/jaxvis-lab
```
